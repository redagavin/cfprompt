# Examples

Each script can be run directly:

```bash
cd examples/
python 01_quickstart.py
```

- **01_quickstart.py** — minimal end-to-end run on a tiny synthetic dataset (no GPU, no API).
- **06_load_and_test_only.py** — laptop-side analysis of cached results, no GPU required.

Examples 02-05 (MedQA gender, BiB directional regression, save & resume, OpenAI classification) are not yet shipped; see the paper for the corresponding analyses.
